## src/Sanitization.Core/HistoryRewriter.cs

### HistoryRewriter (line 6)

Rewrites git history natively: git fast-export | (filter in memory) | git fast-import.
Nothing sensitive is written to disk and no extra tool (git-filter-repo) is needed.
Remote-tracking refs (refs/remotes/*) and the stash are left alone, so the app can still tell what the
remote has until you push. Commits keep their dates and authors (except the e-mails you chose to replace).

### HistoryRewriter.ParseChangePath (line 156)

## src/Sanitization.Core/Report.cs

### Report (line 9)

The HTML report is never written to disk: it is served once from memory over 127.0.0.1 with a random one-time
address and "Cache-Control: no-store" (the browser doesn't cache it either). After the browser loads it, the
server stops. Closing or reloading the tab makes it disappear for good.

### Report.ServeOnce (line 60)

Starts a one-shot loopback server and returns the URL. The server stops after one page load or 2 minutes.
